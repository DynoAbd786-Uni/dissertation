EXECUTIVE SUMMARY
================================================================================
Investigation into step-like fluctuations observed in Wall Shear Stress (WSS) 
calculations when using realistic flow profiles (Poiseuille/blunted) versus 
smooth WSS from uniform profiles. Analysis reveals fundamental discretization 
artifacts and strategic trade-offs between physical realism and computational 
cleanliness.

KEY FINDINGS
================================================================================

1. ROOT CAUSE OF WSS FLUCTUATIONS
   - NOT related to u_max scaling parameters (initially suspected)
   - Caused by fundamental discretization artifacts on lattice grid
   - Discrete sampling of continuous mathematical profiles creates velocity steps
   - WSS calculation (∂u/∂y) amplifies these discrete steps into fluctuations

2. MECHANISM OF THE PROBLEM
   
   Discrete Lattice Sampling:
   - Poiseuille profile: u = u_max * (1 - (r/R)²)
   - At integer lattice coordinates:
     * y=160: velocity = u_max * 0.9975
     * y=161: velocity = u_max * 0.9991  
     * y=162: velocity = u_max * 0.9999
   
   WSS Amplification:
   - WSS ∝ ∂u/∂y ≈ (u[i+1] - u[i-1]) / (2*dx)
   - Small velocity differences become significant WSS steps
   - Example: WSS[161] ∝ (0.9999 - 0.9975) / (2*dx) = 0.0024 / (2*dx)

3. WHY UNIFORM PROFILE WORKS SMOOTHLY
   - Uniform velocity = constant across all lattice points
   - WSS ∝ (constant - constant) / (2*dx) = 0 everywhere
   - No spatial gradients = no discrete artifacts
   - BUT: Completely unphysical for blood flow

4. NUMERICAL SCALING INVESTIGATION
   - Original u_max scaling system was already correct
   - Double-scaling (multiply by u_max, then divide by u_max) was intentional
   - u_max acted as velocity limiter/normalizer for stability
   - Removing u_max broke the carefully balanced system
   - Lesson: "If it ain't broke, don't fix it"

FLOW PROFILE TRADE-OFFS ANALYSIS
================================================================================

OPTION 1: UNIFORM PROFILE + EXTENDED LENGTH
--------------------------------------------
Pros:
✓ Smooth WSS calculations (no stepping artifacts)
✓ Numerical stability (zero gradients)
✓ Clean data for analysis
✓ No discretization issues

Cons:
✗ Unphysical inlet conditions (blood doesn't enter vessels uniformly)
✗ Extended development length required (~20-30 diameters)
✗ Computational cost: 145mm total vs 15mm current (10x longer)
✗ Questionable scientific validity
✗ May not represent real hemodynamics

Length Requirements:
- Development length: ~20D = 130mm (for 6.5mm diameter)
- Analysis region: 15mm (current requirement)
- Total: 145mm vs current 15mm (10x computational cost)

OPTION 2: REALISTIC PROFILES + WSS ARTIFACTS
---------------------------------------------
Pros:
✓ Physically realistic (matches actual blood flow)
✓ Shorter pipe length (no development region needed)
✓ Computationally efficient (current 15mm length)
✓ Scientific validity (represents real hemodynamics)
✓ Literature precedent (accepted practice)

Cons:
✗ WSS stepping artifacts from discrete sampling
✗ Analysis complexity (need artifact mitigation)
✗ Less immediately clean data

RECOMMENDATION: OPTION 2 WITH MITIGATION
================================================================================

RATIONALE:
----------
1. Scientific Validity > Clean Data
   - Dissertation focuses on REAL blood flow hemodynamics
   - Uniform profiles fundamentally change the physics
   - Reviewers will question unphysical inlet conditions

2. WSS Artifacts Are Manageable
   - Post-processing smoothing can reduce artifacts
   - Spatial averaging for analysis
   - Focus on trends rather than absolute point values

3. Computational Feasibility
   - Option 1: 10x computational cost (unfeasible)
   - Option 2: Same cost + post-processing (manageable)

4. Literature Precedent
   - CFD studies commonly accept discretization artifacts
   - Standard practice: acknowledge + mitigate limitations
   - Physical realism prioritized over numerical perfection

MITIGATION STRATEGIES
================================================================================

1. POST-PROCESSING SMOOTHING
   - Apply Gaussian smoothing to WSS fields
   - Spatial averaging over small windows
   - Filter high-frequency discretization noise

2. ANALYSIS TECHNIQUES
   - Focus on spatial trends rather than point values
   - Compare relative WSS patterns between cases
   - Quantify artifact magnitude vs uniform case

3. DOCUMENTATION
   - Acknowledge discretization limitations in methodology
   - Compare uniform vs realistic profiles
   - Justify trade-off selection

4. POTENTIAL ADVANCED SOLUTIONS (Future Work)
   - Sub-lattice interpolation for profile evaluation
   - Smooth boundary transitions (tanh functions)
   - Higher resolution simulations
   - Profile-specific smoothing kernels

CONCLUSION
================================================================================
The WSS fluctuations are an inherent limitation of discrete lattice methods 
when representing smooth continuous profiles, not a bug in the implementation. 
The choice between uniform (clean but unphysical) and realistic (physical but 
with artifacts) profiles is a fundamental trade-off in computational 
hemodynamics.

RECOMMENDATION: Use realistic blunted profiles with post-processing mitigation 
for scientifically valid results that represent actual blood flow physics.

The original u_max scaling system should be preserved as it was designed for 
numerical stability. The apparent "inefficiency" was actually a carefully 
balanced normalization system.
